# 经济学考研知识库 · 使用说明与功能指南

> 本知识库是一个面向经济学考研复习的本地化记忆卡学习系统，纯静态网页，打开即用。  
> 所有学习数据默认只保存在当前浏览器本地，不会自动上传云端。  
> 建议定期使用“数据同步”导出备份，防止换设备、换浏览器或清理缓存导致数据丢失。

---

## 一、总览

本知识库把微观经济学、宏观经济学、计算题、简答题、论述题、历年真题等内容拆分成一张张记忆卡，配合筛选、随机抽查、收藏、笔记、编辑、自测、AI 答疑、学习进度、朗读、数据备份等功能，帮助使用者系统复习、背诵、刷题和查漏补缺。

知识库共分 **八大模块**：背诵（微观）、背诵（宏观）、计算要点、计算专项、简答专项（微观）、简答专项（宏观）、论述专项、历年真题。每个模块内部都按章节、专题、题型或套卷组织，卡片可以展开答案、收藏、写笔记、编辑，也可以进入随机抽查和自测模式。

学习数据默认保存在当前浏览器本地。换设备、换浏览器、清理缓存、使用无痕模式，都可能导致数据丢失，因此建议定期导出 JSON 备份。AI 对话会发送到你自行配置的 API 服务商，请自行注意 API Key 和隐私安全。

## 二、快速开始

第一次使用，打开首页后可以看到八个模块卡片。点击任意模块，即可进入对应的记忆卡页面。在卡片页面中，点击题目区域可以展开或收起答案；点击 ☆ 收藏重点卡片；点击 📝 添加笔记；点击 ✏️ 编辑题目或答案。顶部筛选栏用于按章节、专题、专业、套卷、题型、收藏状态或关键词筛选，搜索会实时过滤卡片。

如果想检验记忆，可以点击“🎲 随机抽查”或按键盘 `R` 键进入随机抽查模式。抽查模式中，顶部显示当前卡片标签，点击 `◀`、`▶` 或键盘左右方向键可以切换卡片，按 `Esc` 或点击 `✕` 退出。随机抽查只从当前筛选结果中抽取，如果先筛选了章节或收藏，再随机抽查，就只会在该范围内抽取。

如果需要 AI 答疑，点击页面右下角悬浮按钮。第一次使用先配置 API，配置完成后即可围绕当前卡片提问。学习一段时间后，回到首页，在“学习进度”输入框记录今天背到哪、哪块还没搞懂、下一步计划等，并可点击朗读按钮听一遍。最后，定期点击首页“同步”按钮，导出 JSON 备份，防止数据丢失。

## 三、首页功能

首页是整个知识库的总入口，包含模块卡片区、学习进度记录、朗读控件、清除数据和数据同步五个部分。模块卡片区展示八个模块卡片，每个卡片显示图标、名称、说明、卡片数量和“进入 →”提示，点击即可进入对应模块。

学习进度输入框位于首页底部，可以随手记录今日任务、复习进度、薄弱章节、明日计划、错题提醒或考前冲刺安排。输入内容会自动保存到本地，输入框右侧会短暂显示“已保存”。学习进度输入框右侧有朗读控件，点击喇叭按钮可以朗读当前学习进度内容，再次点击可以暂停，继续点击可以恢复朗读；右侧滑块可以调整语速，范围通常为 0.5× 到 2.0×。如果当前浏览器不支持语音合成，朗读按钮会被禁用。朗读功能适合把要背的知识点、计划、易错提醒复制到学习进度框中，然后直接收听。

点击首页“清除”按钮后，会展开花瓣状选择器，每片花瓣对应一个模块。点击选择需要清除数据的模块，可多选；再次点击中间按钮，弹出确认框；确认后，所选模块的收藏、笔记、编辑、自测标记等本地数据会被清除，学习进度记录也会一并重置。此操作不可恢复，请谨慎使用，清除前建议先导出备份。

点击首页“同步”按钮后，上下展开两个小球：📥 导入用于从 JSON 文件恢复数据，📤 导出用于把本地数据保存为 JSON 文件。导出时可以勾选学习数据（必导）、AI 配置（可选，不含 API Key）和 AI 对话历史（可选）。在普通浏览器中，导出会直接下载 JSON 文件；在微信内置浏览器中，由于不能直接下载，会弹出分段复制窗口，需要按顺序复制每一段，粘贴到电脑记事本的同一个文件中，保存为 `.json` 文件。导入时，同名记录会被覆盖，本机独有而文件里没有的记录会保留，导入 AI 配置时本机已有的 API Key 不会被覆盖，导入完成后页面会刷新。微信内置浏览器和手机浏览器是两套独立存储，数据不共享；如果在微信中学习，建议定期导出备份到电脑。

## 五、单张记忆卡操作

每个模块中的卡片操作基本一致。点击题目区域可以展开答案，再次点击可以收起。如果该卡片已有笔记，展开答案时可能会同时展开笔记区域。历年真题页比较特殊：真题页通常没有答案区，点击题目区域展开的是“作答区 / 笔记区”，用于写自己的答案、思路和总结。

点击 ☆ 按钮可以收藏卡片，收藏后按钮变为 ⭐，卡片左侧边框和背景会变化。在筛选栏中选择“仅收藏”，可以只看收藏卡片。点击 📝 按钮打开笔记区域，支持输入文字、粘贴图片、插入图片、调整图片大小、保存笔记和清空笔记。笔记内容保存在本地浏览器中，点击笔记中的图片可以调出大小滑块，调整图片显示比例。

点击 ✏️ 按钮可以编辑当前卡片的题目和答案，编辑后点击 💾 保存，或点击 ❌ 取消。编辑内容只保存在本地，不会修改原始数据文件，保存后后续打开卡片会显示编辑后的内容。卡片顶部通常显示所属章节 / 专题 / 专业、题号、是否有图示。如果显示“📐 有图示”，说明该题可能涉及图形分析，建议结合教材或自行画图理解。

## 六、筛选、搜索与随机抽查

不同模块的筛选条件不同。背诵模块按章节和类型筛选，计算要点按专题筛选，计算专项按专项和细分专项筛选，简答模块按专项筛选，论述模块按层次筛选，历年真题按专业、套卷和题型筛选。筛选后页面只显示符合条件的卡片。

在搜索框中输入关键词，可以搜索题目和答案内容，搜索会实时过滤卡片。选择“仅收藏”，只显示已收藏卡片，适合考前只看重点。点击“🎲 随机抽查”或按键盘 `R` 键，可以从当前筛选结果中随机抽取一张卡片，进入抽查模式。抽查模式中，顶部显示当前卡片标签，点击 `◀`、`▶` 切换卡片，键盘左右方向键也可以切换，按 `Esc` 或点击 `✕` 退出抽查模式。抽查时筛选栏会被禁用，退出后恢复。随机抽查只从当前筛选结果中抽取，如果先筛选了章节或收藏，再随机抽查，就只会在该范围内抽取。

## 七、自测模式与错题本

八个子页面都带有“自测模式”开关，默认关闭，关闭时对原有页面零影响。打开后，答案被遮住，先自己默背，再点“查看答案”对照，然后自评“会了 / 模糊 / 忘了”。点同一个键可清除标记，统计条能按标记筛选，答案也能重新遮住，反复默写。遮罩本身点不动，防止手机误触。关闭开关后，卡片外观、按钮、提示全部恢复原样。统计条可以筛选全部、只看不会的、会了、模糊、忘了、未测。自测标记存在各自模块的 `selftest` 存储中，会跟着学习数据一起导出。

历年真题页没有答案区，因此那里不做遮答案，改用“错题本”模式：只做掌握度标记和筛选，作答区照常使用。可以标记“会了 / 模糊 / 忘了”，可以按标记筛选，适合刷真题时记录掌握程度。

## 八、笔记系统

笔记系统适合记录自己的理解、易错点、补充公式、图形截图、老师讲解、真题答案框架、背诵口诀等内容。点击卡片上的 📝 按钮打开笔记区，在编辑区输入文字，点击“🖼️ 插入图片”选择本地图片，也可以直接复制图片后粘贴到笔记区，点击“💾 保存笔记”保存内容，点击“🗑️ 清空”清除该卡片笔记。点击笔记中的图片，可以拖动滑块调整图片大小，点击“重置”可以恢复图片默认大小。笔记保存在浏览器本地，不会上传到服务器。

笔记支持自动保存，写一半关掉页面会有提醒；插入的图片会自动压缩后再保存；如果浏览器存储不够，会明确提示“没保存成功”。子页笔记区改成点开只看、点文本框才编辑，空笔记和有笔记的卡片行为一致；有笔记的卡片默认展开笔记；点击答案区时，答案与笔记一同显示；点击笔记图标只显示笔记，不显示答案。

## 九、编辑系统

编辑功能适合修正题目中的错别字、补充答案要点、调整表述、加入自己的记忆方法。点击卡片上的 ✏️ 按钮，题目和答案会变为可编辑状态，修改完成后点击 💾 保存，如需放弃修改点击 ❌ 取消，保存后卡片会显示修改后的内容。

注意编辑只影响本地浏览器，不会修改原始文件；清除数据或清理缓存后编辑内容可能丢失。取消编辑可以恢复当前编辑前的内容；如果已经保存，需要手动改回，或清除该模块数据后重新打开。

## 十、AI 答疑助手

AI 答疑助手是本知识库的智能问答功能，入口在页面右下角悬浮按钮。

首次点击 AI 按钮，会进入配置界面，需要填写服务商、API 地址（Base URL）、模型名称、API Key 和系统提示词。配置只保存在本地浏览器中，导出数据时 AI 配置不含 API Key，避免泄露。如果想让它识别图片，需要填写支持视觉的模型，例如视觉版大模型；普通文本模型无法看图。默认系统提示词主要覆盖微观经济学和宏观经济学，默认不专门涉及政治经济学、计量经济学、金融学专业课内容；如果需要其他内容，可以在设置中自行修改系统提示词。

AI 助手会读取当前页面上下文，包括当前模块、当前可见卡片、卡片标签、题干、已展开答案、用户笔记、同屏其他卡片和当前筛选条件。它会优先根据当前卡片回答；如果用户切换了卡片，它会识别焦点变化，尽量按新卡片回答。在自测模式下，答案没被遮住的时候 AI 能读到答案；只有答案被遮罩时才读不到。AI 会盯着用户正在看的那张卡片，减少“明明看到了却说没看到”的情况。

AI 助手支持 Markdown 渲染、LaTeX 公式渲染、表格、代码块、复制回复、重新生成、删除单条消息、上传图片、上传文本文件、粘贴图片、查看大图、对话进度条跳转、暂停生成、继续生成、拖拽调整面板大小和清空对话。桌面端 Enter 发送，或在生成中暂停；Shift + Enter 换行；生成中发送键变为暂停键；暂停后可以点击“继续生成”，也可以输入新问题发送，新问题会截断当前回答。移动端 Enter 默认换行，点击发送按钮发送。

上传附件支持图片和文本文件，限制通常为最多 6 个附件，图片压缩后上传，文本文件过大时会截断，图片单张上限约 12MB，文本文件单份上限约 2MB / 20000 字。上传的图片可以点击查看大图；如果模型不支持视觉，图片内容可能无法被正确识别。

对话区右侧有短横线进度条，鼠标悬停可以显示提问列表，点击可以跳转到对应提问，进度条长了可以滚动。点击 AI 面板顶部的清空按钮，可以清空所有对话历史，此操作不可恢复。

AI 对话可以分享链接，做成勾选式：只把勾选的那几条生成链接，没勾的不会进链接。打开分享链接后，是一个铺满整屏的 AI 对话窗口，只显示分享的对话片段，不带出知识库网页，只能复制，不能重新生成、删除或继续提问，不会消耗 tokens，标签页显示“来自分享的对话”。分享链接因为要带上完整对话内容，可能偏长；如果转发时被截断，打开时会有提示。分享视图为纯只读：不显示输入框，不显示进度条，隐藏头部按钮，不显示拖拽手柄，不出现“继续生成”，不渲染“重新生成”和“删除”，只保留“复制”。

## 十一、数据备份与恢复

数据同步用于在不同时间点备份和恢复学习数据。点击首页“同步”按钮，再点击 📤 导出，弹出选择框后，可以勾选学习数据（必导，包括收藏、笔记、编辑、学习进度、自测标记等）、AI 配置（可选，不含 API Key）和 AI 对话历史（可选）。普通浏览器会直接下载 JSON 文件；微信内置浏览器会弹出分段复制窗口，需要按顺序复制每一段，粘贴到电脑记事本的同一个文件中，保存为 `.json` 文件。

点击首页“同步”按钮，再点击 📥 导入，选择之前导出的 JSON 文件，确认后数据会写入本地浏览器。导入规则是同名记录会被覆盖，本机独有而文件里没有的记录会保留，导入 AI 配置时本机已有的 API Key 会保留，不会被文件覆盖，导入完成后页面会刷新。微信内置浏览器和手机浏览器是两套独立存储，数据不共享；如果在微信中学习，建议定期导出备份到电脑；微信中导出时，必须把所有分段复制完整并拼接，否则导入会失败。

## 十二、学习进度、朗读与清除数据

学习进度输入框位于首页底部，可以记录今日任务、复习进度、薄弱章节、明日计划、错题提醒等内容，输入后自动保存。点击朗读按钮，可以朗读当前内容，语速可以调整，设置会保存在本地。

清除数据功能用于删除本地学习记录。操作方式是点击首页“清除”按钮，花瓣展开，每片花瓣对应一个模块，点击选择要清除的模块，再次点击中间按钮，确认后所选模块的收藏、笔记、编辑、自测标记等数据会被删除，学习进度记录也会被重置，操作不可恢复。建议在清除前先导出备份。清除模块数据主要清除对应模块的学习记录和学习进度；AI 配置和对话历史有独立入口，可通过 AI 助手设置或清空对话管理；导出时也可以选择是否包含 AI 配置和对话历史。

## 十四、推荐学习流程

第一阶段打基础：使用“背诵（微观）”和“背诵（宏观）”过概念，对不熟的卡片点击收藏，用笔记补充自己的理解，每天记录学习进度。

第二阶段练计算：使用“计算要点”学习每类题的解题思路，使用“计算专项”集中刷题，把错题和易错步骤写进笔记，用随机抽查检验掌握程度。

第三阶段背简答与论述：使用“简答专项（微观）”和“简答专项（宏观）”按专题背诵答题框架，使用“论述专项”学习如何结合材料，收藏高频题和薄弱题。

第四阶段真题模拟：进入“历年真题”，按专业、套卷、题型筛选，按套卷限时模拟，对答案整理错题和答题思路，用 AI 助手追问不懂的地方。

第五阶段冲刺回顾：只看收藏卡片，随机抽查，复习笔记和编辑过的卡片，定期导出备份，记录考前计划。

## 十五、常见问题

**数据会丢失吗？** 数据保存在当前浏览器本地。换设备、换浏览器、清理缓存、使用无痕模式，都可能导致数据丢失。建议定期导出备份。

**微信里和手机浏览器数据一样吗？** 不一样。微信内置浏览器和手机浏览器是两套独立存储。如果想同步，需要导出 JSON 再在另一个环境导入。

**AI 不回复怎么办？** 检查 API Key 是否正确、API 地址是否正确、模型名称是否正确、账户是否有余额、网络是否能访问该接口、服务商是否允许浏览器直连。

**上传图片后 AI 看不懂？** 可能当前模型不支持视觉，请换成支持视觉的模型。

**公式显示不正常？** 公式渲染依赖外部资源。如果网络不好，可能显示为备用格式。刷新页面或检查网络后重试。

**笔记图片太多会怎样？** 图片和笔记会占用浏览器存储空间。如果存储空间不足，保存可能失败。建议导出备份后清理不必要的大图。

**编辑后能恢复原始内容吗？** 编辑只保存在本地。取消编辑可以恢复当前编辑前的内容。如果已经保存，需要手动改回，或清除该模块数据后重新打开。

**清除数据会清除 AI 配置吗？** 清除模块数据主要清除对应模块的学习记录和学习进度。AI 配置和对话历史有独立入口，可通过 AI 助手设置或清空对话管理。导出时也可以选择是否包含 AI 配置和对话历史。

**自测标记如何保存？** 自测标记存在各自模块的 `selftest` 存储中，会跟着“学习数据”一起导出。

**分享链接为什么很长？** 因为分享链接要带上完整对话内容，所以会比较长。可以只勾选几条关键对话再生成链接。

本知识库是纯静态网页，主要技术包括 HTML / CSS / JavaScript、浏览器 localStorage 本地存储、语音合成 API、文件读取 API、Canvas 图片压缩、Markdown 渲染、LaTeX 公式渲染和流式 AI 接口调用。数据不会自动上传到云端。AI 对话会发送到所配置的 API 服务商，请自行注意 API Key 和隐私安全。

本知识库适合经济学考研的长期复习和冲刺阶段使用。核心用法可以概括为：用八大模块系统学习，用卡片展开答案、收藏、笔记、编辑，用筛选和搜索定位内容，用随机抽查检验记忆，用自测模式检查掌握程度，用 AI 助手答疑，用学习进度记录计划，用朗读功能辅助复习，用数据同步定期备份。建议把“收藏 + 笔记 + 随机抽查 + 自测 + 真题模拟 + 导出备份”作为固定学习闭环，坚持使用，效果最好。
