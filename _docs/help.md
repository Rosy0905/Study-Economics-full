# 经济学考研知识库 · 使用说明与功能指南

本知识库是一个面向经济学考研复习的本地化记忆卡学习系统，纯静态网页，打开即用。  
所有学习数据默认只保存在当前浏览器本地，不会自动上传云端。  
建议定期使用“数据同步”导出备份，防止换设备、换浏览器或清理缓存导致数据丢失。

---

## 一、开始使用

### 1. 这个知识库是什么

本知识库把微观经济学、宏观经济学、计算题、简答题、论述题、历年真题等内容拆分成一张张记忆卡，配合筛选、筛选记忆、模块间串连切换、随机抽查、收藏、笔记、编辑、自测、AI 答疑、学习进度、朗读、数据备份等功能，帮助使用者系统复习、背诵、刷题和查漏补缺。

知识库共分 **八大模块**：背诵（微观）、背诵（宏观）、计算要点、计算专项、简答专项（微观）、简答专项（宏观）、论述专项、历年真题。每个模块内部都按章节、专题、题型或套卷组织，卡片可以展开答案、收藏、写笔记、编辑，也可以进入随机抽查和自测模式。

历年真题页还带一个 **真题答案册**：把历年真题的参考答案集中到一个页面里，可以逐套卷翻查，也可以直接搜索（见 4.1）。

此外还有 **“我的卡片”**：一个自定义卡片页，用来存放自己整理的卡片、从 AI 回答里导出的卡片，写法和八大模块里的卡片一致（题目 + 富文本答案 + 收藏 + 章节归类）。

学习数据默认保存在当前浏览器本地。换设备、换浏览器、清理缓存、使用无痕模式，都可能导致数据丢失，因此建议定期导出 json 备份。AI 对话会发送到你自行配置的 API 服务商，请自行注意 API Key 和隐私安全。

### 2. 第一次怎么用

第一次使用，打开首页后可以看到八个模块卡片，下方还有一条“我的卡片”通栏。点击任意模块，即可进入对应的记忆卡页面；点击“我的卡片”，可以自己新建卡片。

在卡片页面中，点击题目区域可以展开或收起答案；点击 ☆ 收藏重点卡片；点击 📝 添加笔记；点击 ✏️ 编辑题目或答案。顶部筛选栏用于按章节、专题、专业、套卷、题型、收藏状态或关键词筛选，搜索会实时过滤卡片。

如果想检验记忆，可以点击“🎲 随机抽查”或按键盘 `R` 键进入随机抽查模式。抽查模式中，顶部显示当前卡片标签，点击 `◀`、`▶` 或键盘左右方向键可以切换卡片，按 `Esc` 或点击 `✕` 退出。随机抽查只从当前筛选结果中抽取，如果先筛选了章节或收藏，再随机抽查，就只会在该范围内抽取（见 5.3）。

如果需要 AI 答疑，点击页面右下角悬浮按钮（八个模块页和“我的卡片”页都有）。第一次使用先配置 API，配置完成后即可围绕当前卡片提问（见 6）。学习一段时间后，回到首页，在“学习进度”输入框记录今天背到哪、哪块还没搞懂、下一步计划等，并可点击朗读按钮听一遍。最后，定期点击首页“同步”按钮，导出 json 备份，防止数据丢失。

### 3. 页面之间怎么切换

顶栏左上角「← 主页」可以退回首页；在首页点击任意模块卡片即可进入对应模块。顶栏「← 主页」右侧还有一颗写着序号的小圆钮，点开可以直接跳到别的模块（新开一页，当前这页不关），不必先回首页再进；面板的详细用法见 3.2。

### 4. 键盘快捷键

| 快捷键              | 功能                            |
| ---------------- | ----------------------------- |
| `R`              | 随机抽查                          |
| `Esc`            | 退出抽查模式，或关闭已展开的弹层（串连导航面板、确认框等） |
| `←`              | 抽查模式中上一张                      |
| `→`              | 抽查模式中下一张                      |
| `Ctrl / Cmd + B` | 笔记区、答案区：加粗                    |
| `Ctrl / Cmd + I` | 笔记区、答案区：斜体                    |
| `Ctrl / Cmd + U` | 笔记区、答案区：下划线                   |

输入框、文本编辑区中按 `R` 不会触发随机抽查。

## 二、首页与进度

首页是整个知识库的总入口，包含模块卡片区、“我的卡片”入口、学习进度记录、朗读控件、清除数据和数据同步几个部分。

### 1. 模块卡片区

模块卡片区展示八个模块卡片，每个卡片显示图标、名称、说明、卡片数量和“进入 →”提示，点击即可进入对应模块。模块卡片区下方是一条通栏“我的卡片”，点击进入自定义卡片页。

### 2. 学习进度

学习进度记录放在首页底部，可以随手记下今日任务、复习进度、薄弱章节、明日计划、错题提醒或考前冲刺安排。点击那条进度条会弹出一张卡片来编辑，输入内容停手一会儿会自动保存，卡片顶部会显示最后保存的时间。

### 3. 朗读

点击喇叭按钮可以朗读当前学习进度内容，再次点击可以暂停，继续点击可以恢复朗读；右侧滑块可以调整语速，范围通常为 0.5× 到 2.0×，设置会保存在本地。如果当前浏览器不支持语音合成，朗读按钮会被禁用。改字会同时停掉朗读（念的已经是旧内容了），再点喇叭可以重新读。朗读功能适合把要背的知识点、计划、易错提醒写进学习进度里，然后直接收听。

### 4. 清除数据

点击首页“清除”按钮后，会展开花瓣状选择器，每片花瓣对应一个模块。点击选择需要清除数据的模块，可多选；再次点击中间按钮，弹出确认框；确认后，所选模块的收藏、笔记、编辑、自测标记等本地数据会被清除，学习进度记录也会一并重置；真题模块的数据被清除时，答案册的搜索词和滚动位置也会一起清掉，重新打开不会被旧状态带着走。此操作不可恢复，请谨慎使用，清除前建议先导出备份。“我的卡片”里的内容不在花瓣选择器里，需要在“我的卡片”页面顶部用那颗绿色小球单独清空。

清除模块数据主要清除对应模块的学习记录和学习进度；AI 配置和对话历史有独立入口，可通过 AI 助手设置或清空对话管理；导出时也可以选择是否包含 AI 配置和对话历史。

### 5. 数据同步

点击首页“同步”按钮后，上下展开两个小球：📥 导入用于从 json 文件恢复数据，📤 导出用于把本地数据保存为 json 文件。导出时可以勾选学习数据（必导，现已包含“我的卡片”的卡片和章节）、AI 配置（可选，不含 API Key）和 AI 对话历史（可选）。导入时，备份里带着哪个模块的内容，本机对应模块就整块替换；导入 AI 配置时本机已有的 API Key 不会被覆盖，导入完成后页面会刷新。导出、导入、整块替换规则，以及微信内置浏览器里的分段复制方法，详见 7。

### 2. 模块之间直接切换

面板的列数跟着窗口宽度走，电脑上排成 4 列、3 列或 2 列；手机上（宽度 ≤640）顶栏本来就会堆成几行，所以面板改成从屏幕底部弹出、背后加一层浅色遮罩，不挡顶部内容。

## 四、附加模块

除八大模块外，知识库还有两个附加页面：真题答案册和“我的卡片”。

### 1. 真题答案册

历年真题的参考答案集中放在一个页面里，做成一个可以逐套卷翻查、随手搜索的答案册。

#### 1.1 入口与跳转

真题页顶栏有「答案册」按钮，点开就进答案册；真题页每张题卡右上角的 📖 按钮，也能直接跳到这道题在答案册里的位置。答案册左上角「⬅ 题库」退回真题页。

#### 1.2 里面有什么

按专业和年份收录各套真题的参考答案，左侧有学科和年份切换，右侧是该套卷的题目列表。题目按小问排版，公式单独成行显示。

#### 1.3 搜索

顶部搜索框可以搜全部真题的题干和答案，命中在答案里的结果会标出「命中在答案里」。搜索结果跨套卷汇总，并提供「← 回到全站搜索结果」返回真题页的搜索结果。搜索框右边是「清空搜索」。

#### 1.4 档位筛选

答案册顶部统计条可以按自测档位筛（只看不会的 / 会了 / 模糊 / 忘了 / 未测），选定的档位会被记住。档位不是「全部」时，搜索只在这个档位范围内进行，页面上会写明当前范围，并提供「不限档位 · 重搜全站」把范围放开。

#### 1.5 回到顶部

向上滑动一段距离后，右下角会出现一枚浅绿箭头按钮，点一下就平滑回到页首；往下滚或停下来不动时它会自己藏回去。

### 2. 我的卡片

“我的卡片”是从首页下方通栏进入的第九个页面，用来放自己整理的内容：教材上抄下来的结论、做题时踩过的坑、老师讲的点拨，或者从 AI 回答里导出的卡片。数据一样只保存在本机浏览器。这一页右下角也有 AI 助手浮球，和八个模块页共用同一套，用法见 6。

#### 2.1 新建与整理

**新建卡片**：点击“＋ 新建卡片”，填写序号（可选）、章节、题目，答案区是一个富文本编辑器，可以加粗、斜体、下划线、插入图片、插入表格、写公式；如果这道题要配图分析，可以勾选“📐 有图示”做标记。

**整理卡片**：卡片列表可以按章节筛选、按题目关键词搜索；卡片顺序默认按拼音首字母排（中文按拼音、英文按字母，数字按自然序）；可以收藏重点卡片，可以编辑或删除，章节也可以在章节面板里拖动排序。章节按“微观 / 宏观”两个分类分开管理。

#### 2.2 从 AI 对话导入

点击“从 AI 对话导入”，可以把 AI 答疑助手里的问答一键变成卡片 —— 一问一答算一张，题目取你的提问，答案取 AI 的回答，导入时可以指定放到哪个分类和章节。

#### 2.3 存成卡片

在任意模块页的 AI 面板里，每条回答右下角都有一枚「存成卡片」，点开先看题目和答案预览（题目可以改、分类和章节可以选），确认后才写进来，取消则不写。已存过的同一条不会重复存，再点一下是「移出卡片」。这一页不用手动刷新：存完会立刻多出这张卡，并且自动滚到它眼前、外圈亮一圈淡绿光晕约 2 秒，方便确认。要是当前筛选正好把它挡住了，页面不会硬把你拽走，只提示它进了哪个分类和章节。

反过来，从 AI 助手那边也能直接把回答收成卡片，不必先回“我的卡片”页：AI 面板右上角最左边有一枚卡片图标，点它会在新标签页打开“我的卡片”；把鼠标移到任意一条 AI 回答上（手机上是点一下回答区域），回答右下角会出现一枚卡片图标，点它就把“你的提问 + 这条回答”存成一张卡片 —— 提问当题目、回答当答案，Markdown 会自动转成富文本（表格、公式、加粗都能保留）。已经存过的同一条不会重复存，会提示“这张卡片已经有了”。存好后按钮变深绿，顺手去看看就点右上角那枚卡片图标。

这一步在“我的卡片”页里也一样能用。如果“我的卡片”正在另一个标签页开着，存完它会立刻多出这张卡，并自动滚到它眼前、外圈亮一下；要是从子页点右上角图标新开标签过去，则是普通打开，落在页面顶部。

#### 2.4 备份与清空

页面右上角两颗小球，绿色那颗是“清空全部数据”（卡片和章节一起清），青色那颗点开是“导入 / 导出 json”。首页“同步”的导出也会把这里的内容一起带上。

## 五、卡片与学习工具

### 1. 单张卡片操作

每个模块中的卡片操作基本一致。点击题目区域可以展开答案，再次点击可以收起。如果该卡片已有笔记，展开答案时可能会同时展开笔记区域。历年真题页比较特殊：真题页通常没有答案区，点击题目区域展开的是“作答区 / 笔记区”，用于写自己的答案、思路和总结。

点击 ☆ 按钮可以收藏卡片，收藏后按钮变为 ⭐，卡片左侧边框和背景会变化。在筛选栏中选择“仅收藏”，可以只看收藏卡片。点击 📝 按钮打开笔记区域，支持富文本编辑（见 5.5）。

点击 ✏️ 按钮可以编辑当前卡片的题目和答案，编辑后点击 💾 保存，或点击 ❌ 取消。编辑内容只保存在本地，不会修改原始数据文件，保存后后续打开卡片会显示编辑后的内容。卡片顶部通常显示所属章节 / 专题 / 专业、题号、是否有图示。如果显示“📐 有图示”，说明该题可能涉及图形分析，建议结合教材或自行画图理解。

### 2. 筛选与搜索

不同模块的筛选条件不同。背诵模块按章节和类型筛选，计算要点按专题筛选，计算专项按专项和细分专项筛选，简答模块按专项筛选，论述模块按层次筛选，历年真题按专业、套卷和题型筛选。筛选后页面只显示符合条件的卡片。

在搜索框中输入关键词，可以搜索题目和答案内容，搜索会实时过滤卡片。选择“仅收藏”，只显示已收藏卡片，适合考前只看重点。

**筛选会被记住。** 选过的章节、专题、专业、套卷、题型、收藏状态，以及在搜索框里敲的关键词，刷新页面、关掉重开、第二天再来都还在，不用每次重新选一遍。每个模块各记各的（微观筛到第 3 章不会带到宏观），「我的卡片」也是单独一套。

想清掉：点筛选栏的「重置筛选」，几个下拉和搜索框会一起被清空，记忆随之清掉。这个按钮不管自测开关和自测统计条，那两个各自记自己的（把开关关掉、或把统计条切回「全部」，记下的就是新状态）。章节被改名或删掉之后，那条旧选择会自动回落成「全部」，不会卡在一个已经不存在的选项上，也不会让页面变空白。

这套记忆只存选项本身，不动卡片数据；浏览器存储受限时（比如部分旧版浏览器的无痕窗口）会安静地不记，筛选照常可用。

### 3. 随机抽查

点击“🎲 随机抽查”或按键盘 `R` 键，可以从当前筛选结果中随机抽取一张卡片，进入抽查模式。抽查模式中，顶部显示当前卡片标签，点击 `◀`、`▶` 切换卡片，键盘左右方向键也可以切换，按 `Esc` 或点击 `✕` 退出抽查模式。抽查时筛选栏会被禁用，退出后恢复。随机抽查只从当前筛选结果中抽取，如果先筛选了章节或收藏，再随机抽查，就只会在该范围内抽取。

抽查还跟着自测走：如果自测开着、统计条停在某个档位（比如只看不会的），就只在这一档里抽；统计条在「全部」或自测没开时，照旧抽全池。

### 4. 自测模式与错题本

八个子页面都带有“自测模式”开关，默认关闭，关闭时对原有页面零影响。打开后，答案被遮住，先自己默背，再点“查看答案”对照，然后自评“会了 / 模糊 / 忘了”。点同一个键可清除标记，统计条能按标记筛选，答案也能重新遮住，反复默写。遮罩本身点不动，防止手机误触。关闭开关后，卡片外观、按钮、提示全部恢复原样。统计条可以筛选全部、只看不会的、会了、模糊、忘了、未测。自测标记存在各自模块的 `selftest` 存储中，会跟着学习数据一起导出。

**开关和统计条也会记住。** 上次开着还是关着、统计条停在「只看不会的」还是「全部」，刷新后都还原，不用每次重开自测。但**哪几张已经点开过答案不记**：刷新后答案重新遮住，这本来就是自测的意思 —— 重来一遍。如果上次停在「只看不会的」而当前没有标过的卡，列表会是空的（自测筛选本来的表现），点统计条「全部」就回来了。

历年真题页没有答案区，因此那里不做遮答案，改用“错题本”模式：只做掌握度标记和筛选，作答区照常使用。可以标记“会了 / 模糊 / 忘了”，可以按标记筛选，适合刷真题时记录掌握程度。

### 5. 笔记系统

笔记适合记录自己的理解、易错点、补充公式、图形截图、老师讲解、真题答案框架、背诵口诀等。点击卡片上的 📝 按钮打开笔记区：默认是“只看”状态，点一下笔记文本框才进入编辑，这样不会一不小心改到笔记。

#### 5.1 工具栏

进入编辑后，笔记框下方是一排富文本工具栏：

| 按钮       | 作用                                              |
| -------- | ----------------------------------------------- |
| **B**    | 加粗                                              |
| *I*      | 斜体                                              |
| <u>U</u> | 下划线                                             |
| 🧹 清除格式  | 选中文字 → 去掉加粗 / 斜体 / 下划线；只是光标停着 → 后面打的字不再跟着前面的样式走 |
| 🖼️ 插入图片 | 选择本地图片插入（也可以直接粘贴截图）                             |
| ▦ 插入表格   | 弹窗里填行数和列数，自动带上表头                                |
| ∑ 行内公式   | 插入 `$公式$`，把中间两个字换成自己的 LaTeX                     |
| ∑ 块级公式   | 插入 `$$公式$$`，公式单独占一行                             |
| 💾 保存    | 保存笔记（电脑上显示“保存笔记”，手机上显示“保存”）                     |
| 🗑️ 清空   | 清空这张卡片的笔记                                       |

电脑端按钮显示完整名称，手机端自动换成短名称（“图片 / 表格 / 行内 / 块级 / 保存 / 清格式”），窄屏也是两行排得下。“我的卡片”页面的答案区用的是同一套工具栏。

#### 5.2 图片

插入的图片会自动压缩后再保存。编辑状态下点图片，会弹出一条像素尺寸条：左边是目标宽度（px），右边显示“原图 宽×高（体积 KB）→ 目标 宽×高（体积 KB）”；拖动滑块可以实时预览，宽高比始终锁定；点“确认压缩”会真的把图片重新采样压小（不只是显示得小），点“取消”则还原。滑块的上限就是笔记框的整行宽，所以拖到底也不会把图片撑出窗口。非编辑状态下点图片，会打开浮层预览，可以放大、缩小、按原始像素 1:1 显示、适应窗口，右上角关闭。

#### 5.3 公式

行内公式写 `$…$`，独占一行的公式写 `$$…$$`，保存后就会渲染成排版好的公式。公式渲染用的是放在网站目录里的本地字体文件，断网也能正常显示。

#### 5.4 保存与安全

笔记支持自动保存，写一半关掉页面会有提醒；如果浏览器存储不够，会明确提示“没保存成功”。有笔记的卡片默认展开笔记；点击答案区时，答案与笔记一同显示；点击 📝 只显示笔记，不显示答案。历年真题页的作答区 / 笔记区用起来完全一样。

### 6. 编辑系统

编辑功能适合修正题目中的错别字、补充答案要点、调整表述、加入自己的记忆方法。点击卡片上的 ✏️ 按钮，题目和答案会变为可编辑状态，修改完成后点击 💾 保存，如需放弃修改点击 ❌ 取消，保存后卡片会显示修改后的内容。

注意编辑只影响本地浏览器，不会修改原始文件；清除数据或清理缓存后编辑内容可能丢失。取消编辑可以恢复当前编辑前的内容；如果已经保存，需要手动改回，或清除该模块数据后重新打开。

## 六、AI 答疑助手

AI 答疑助手是本知识库的智能问答功能，入口在卡片页面右下角的悬浮按钮（八个模块页、“我的卡片”页和真题答案册页都有，首页没有）。

### 1. 首次配置

首次点击 AI 按钮，会进入配置界面，需要填写服务商、API 地址（Base URL）、模型名称、API Key 和系统提示词。配置只保存在本地浏览器中，导出数据时 AI 配置不含 API Key，避免泄露。如果想让它识别图片，需要填写支持视觉的模型，例如视觉版大模型；普通文本模型无法看图。默认系统提示词把范围限定在微观经济学和宏观经济学两门课（覆盖考研 847 的常见章节），并规定了各类题型的答法：概念题先定义后讲直觉、推导题分步标依据、计算题“列式 — 求解 — 说含义”、对比题用表格、答题用“总—分—总”；公式一律写 LaTeX，提到卡片时用卡片的标签指代。

### 2. 读卡开关

面板顶部「AI 答疑助手」右侧有一个「读卡」开关，用来控制发消息时是否自动附带当前卡片。开着（默认）时，AI 会读到你在看的那张卡（标签、题干、已展开的答案、笔记），直接围绕它回答；关掉后完全不读卡片，只按你发送的文字和截图作答 —— 适合把讲义截图直接丢给它提问、不希望它把屏幕上的卡片扯进来。点一下即切、下一条消息立刻生效，刷新后仍记住上次的选择；关着的时候 AI 明确知道自己没有卡片可看，不会硬答，也不会再引用之前读过的卡片。

### 3. 面板功能

AI 助手会读取当前页面上下文，包括当前模块、当前可见卡片、卡片标签、题干、已展开答案、用户笔记、同屏其他卡片和当前筛选条件。它会优先根据当前卡片回答；如果用户切换了卡片，它会识别焦点变化，尽量按新卡片回答。在自测模式下，答案没被遮住的时候 AI 能读到答案；只有答案被遮罩时才读不到。AI 会盯着用户正在看的那张卡片，减少“明明看到了却说没看到”的情况。

AI 助手还支持复制回复、重新生成、删除单条消息、暂停生成、继续生成、拖拽调整面板大小和清空对话。桌面端 Enter 发送，或在生成中暂停；Shift + Enter 换行；生成中发送键变为暂停键；暂停后可以点击“继续生成”，也可以输入新问题发送，新问题会截断当前回答。移动端 Enter 默认换行，点击发送按钮发送。

想确认某条消息到底给 AI 发了什么，可以在浏览器控制台执行 `__AI_SEES__()`，它会原样打印下一条消息将附带的完整提示（只读，不改动任何状态）。

#### 3.1 支持的格式

AI 助手支持 Markdown 渲染、LaTeX 公式渲染、表格和代码块。

#### 3.2 附件顺序

附件栏里的顺序就是你拖进来（或选中）时的顺序，不会因为某张图压得慢就跑到后面去。需要说明的是，资源管理器交给浏览器的那份文件名单，**顺序由系统决定** —— 按住 Ctrl 一个个点选、或者拉框选中时，通常是列表当前排好的顺序（按名称、按修改日期、按大小），而不是你点击的先后；跨文件夹一起拖时更没有固定规律。网页这边只负责原样保留、不打乱。想要固定顺序，先把文件按想要的顺序（比如按名称）排好，再一起拖进来。

#### 3.3 进度条

对话区右侧有短横线进度条，电脑端鼠标悬停、手机端点一下都能弹出提问列表（每行显示对应提问），点击跳转到那一问；列表高度固定且上下留边距，条数再多也不会盖住标题栏或输入框。点击 AI 面板顶部的清空按钮，可以清空所有对话历史，此操作不可恢复。

#### 3.4 上传限制

上传附件支持图片和文本文件，最多同时 6 个，图片压缩后上传，文本文件过大时会截断。上传的图片可以点击查看大图；如果模型不支持视觉，图片内容可能无法被正确识别。

### 4. 附件与拖拽

#### 4.1 三种上传方式

附件有三种加法：点输入框右边的回形针按钮选文件、截图后直接 `Ctrl + V` 粘贴、把文件或图片**直接拖进对话框**。拖动的时候面板会亮一圈绿边、输入框变成绿色虚线，上方浮出一条提示（拖多个会显示「松手添加 N 个文件」），松手就进附件栏；拖到面板外面松手不会加附件，会提示「把文件拖到 AI 答疑助手的窗口里」；还没填 API 配置时聊天区是收起的，此时拖拽不接受，先配好再拖。拖一段纯文字进来则不拦，照常插进输入框。


#### 4.2 容量上限

图片单张上限约 12MB，文本文件单份上限约 2MB / 20000 字。

### 5. 分享对话

AI 对话可以分享，做成勾选式：只把勾选的那几条生成分享，没勾的不会进去。点“生成分享”后可二选一：

#### 5.1 链接

“生成链接” —— 复制一条分享链接，对方打开即可查看所选对话，是一个铺满整屏的只读窗口，只显示分享的对话片段，不带出知识库网页，只能复制，不能重新生成、删除或继续提问，不会消耗 tokens，标签页显示“来自分享的对话”；链接会把对话内容压缩后放进网址，仍会随内容长度增长，转发被截断时打开会有提示。

#### 5.2 图片

“生成图片保存” —— 把所选对话渲染成一张图片，先在页面上预览，可点“保存图片”保存到相册或下载（保存成功后预览会自动关闭），也可以直接长按图片另存；内容较多、链接太长时用图片分享更方便。图片由浏览器本地生成，不经过任何服务器。

分享视图为纯只读：不显示输入框，不显示进度条，隐藏头部按钮，不显示拖拽手柄，不出现“继续生成”，不渲染“重新生成”和“删除”，只保留“复制”。

### 6. 存成卡片

从 AI 回答直接存成卡片的方法见 4.2.3。在“我的卡片”页面，还可以点“从 AI 对话导入”，把问答一键变成自己的卡片（见 4.2.2）。

### 7. 提示词恢复

如果需要别的内容或别的口吻，在设置里改系统提示词即可（改版本会自动套用到你已有的配置上）；想把系统提示词整个删空再点保存，也会自动还原成初始的那一版。

## 七、数据备份与恢复

数据同步用于在不同时间点备份和恢复学习数据，入口在首页“同步”按钮。

### 1. 导出

点击首页“同步”按钮，再点击 📤 导出，弹出选择框后，可以勾选学习数据（必导，包括收藏、笔记、编辑、学习进度、自测标记、“我的卡片”的卡片和章节等）、AI 配置（可选，不含 API Key）和 AI 对话历史（可选）。普通浏览器会直接下载 json 文件。

### 2. 导入

点击首页“同步”按钮，再点击 📥 导入，选择之前导出的 json 文件，确认后数据会写入本地浏览器。导入是**整块替换**——备份文件里带着哪个模块的内容，本机对应模块的记录就整个换成文件里的，不是一张张比较后合并。

### 3. 整块替换规则

举例：

| 你的情况                                                 | 导入后的结果                            |
| ---------------------------------------------------- | --------------------------------- |
| 电脑上微观背诵模块里的 A 卡写了笔记；手机上从没在该模块写过任何笔记，备份里就没有微观背诵的笔记这一块 | 电脑的笔记**原样保留**，不受影响                |
| 电脑上微观背诵模块里的 A 卡写了笔记；手机在该模块记过**别的**笔记后导出备份            | 导入后电脑微观背诵的笔记**整块换成手机那份**，A 卡的笔记会丢 |
| 电脑“我的卡片”有 20 张；手机只有 5 张就导出了备份                        | 导入后“我的卡片”**只剩下手机备份里的那 5 张**       |
| 手机导出时没勾选 AI 对话历史（或某个模块的内容手机上本来就没有）                   | 电脑上对应模块的内容**原样保留**，不受影响           |

再往细看，同一个模块里面，笔记、收藏、自测标记也是**各存各的块**，替换同样以块为单位。例：微观背诵模块里 A、B、C 三张卡，用手机备份导入电脑——

| 卡 | 电脑端（导入前） | 手机端（备份里带的） | 导入后电脑端               |
| - | -------- | ---------- | -------------------- |
| A | 有笔记、已收藏  | 只有自测标记     | 笔记保留；**收藏消失**、多出自测标记 |
| B | 只有自测标记   | 什么都没记      | **自测标记消失**           |
| C | 只有笔记     | 收藏了它       | 笔记保留、**多出收藏**        |

也就是说，备份带了哪块，哪块就**整个换成备份里的样子**（哪怕备份里那份是空的、或只记了别的卡）；备份没带的块，原样不动。同一张卡不会“只换笔记留收藏”——要换就是一整块一起换。

本机有、文件里没有的模块不受影响。拿不准时，先导出一份备份保底。导入 AI 配置时，本机已有的 API Key 会保留，不会被文件覆盖；导入完成后页面会刷新。

### 4. 我的卡片单独导入

“我的卡片”页面右上角小球里的导入是**往里添加**——只会把文件里的卡片加进来，不会删掉本机已有的卡片，重复的会自动跳过。

### 5. 微信浏览器的分段复制

微信内置浏览器中，由于不能直接下载，会弹出分段复制窗口，需要按顺序复制每一段，粘贴到电脑记事本的同一个文件中，保存为 `.json` 文件。微信内置浏览器和手机浏览器是两套独立存储，数据不共享；如果在微信中学习，建议定期导出备份到电脑；微信中导出时，必须把所有分段复制完整并拼接，否则导入会失败。

## 八、学习流程与常见问题

### 1. 推荐学习流程

第一阶段打基础：使用“背诵（微观）”和“背诵（宏观）”过概念，对不熟的卡片点击收藏，用笔记补充自己的理解，每天记录学习进度。

第二阶段练计算：使用“计算要点”学习每类题的解题思路，使用“计算专项”集中刷题，把错题和易错步骤写进笔记，用随机抽查检验掌握程度。

第三阶段背简答与论述：使用“简答专项（微观）”和“简答专项（宏观）”按专题背诵答题框架，使用“论述专项”学习如何结合材料，收藏高频题和薄弱题。

第四阶段真题模拟：进入“历年真题”，按专业、套卷、题型筛选，按套卷限时模拟，对答案整理错题和答题思路，用 AI 助手追问不懂的地方。

第五阶段冲刺回顾：只看收藏卡片，随机抽查，复习笔记和编辑过的卡片，把自己还没记牢的点沉淀到“我的卡片”里，定期导出备份，记录考前计划。

### 2. 常见问题

#### 2.1 数据与备份

**数据会丢失吗？** 数据保存在当前浏览器本地。换设备、换浏览器、清理缓存、使用无痕模式，都可能导致数据丢失。建议定期导出备份。

**微信里和手机浏览器数据一样吗？** 不一样。微信内置浏览器和手机浏览器是两套独立存储。如果想同步，需要导出 json 再在另一个环境导入。

**清除数据会清除 AI 配置吗？** 清除模块数据主要清除对应模块的学习记录和学习进度。AI 配置和对话历史有独立入口，可通过 AI 助手设置或清空对话管理。导出时也可以选择是否包含 AI 配置和对话历史。

**自测标记如何保存？** 自测标记存在各自模块的 `selftest` 存储中，会跟着“学习数据”一起导出。

**刷新后筛选怎么还在，是不是坏了？** 不是，这是特意做的“筛选记忆”：章节、收藏、关键词和自测开关都按模块存着，下次打开自动还原。不想要的话点筛选栏「重置筛选」即可清掉（它清的是几个下拉和搜索框；自测开关和统计条自己切一下，记下的就是新状态）。

**“我的卡片”会跟着备份吗？** 会。首页“同步 → 导出”的学习数据里已经包含“我的卡片”的卡片和章节；也可以在“我的卡片”页面点右上角那颗青色小球单独导出。

#### 2.2 AI 答疑

**AI 不回复怎么办？** 检查 API Key 是否正确、API 地址是否正确、模型名称是否正确、账户是否有余额、网络是否能访问该接口、服务商是否允许浏览器直连。

**上传图片后 AI 看不懂？** 可能当前模型不支持视觉，请换成支持视觉的模型。

**拖多个文件进来，顺序和我点的先后不一样？** 附件栏保持的是浏览器交给我们的那份顺序，而这份名单由资源管理器和系统给出：按住 Ctrl 点选或拉框选中时，通常是列表当前的排列顺序（按名称、日期、大小），不是点击先后。想固定顺序，先把文件按想要的顺序排好再一起拖。网页这边只保证不把顺序打乱（以前图片压缩慢会被挤到最后，现在不会了）。

**分享链接为什么很长？** 因为分享链接要带上完整对话内容，所以会比较长；不过现在已经过压缩，比早期版本短了不少。可以只勾选几条关键对话再生成链接；如果内容确实多，也可以点“生成分享”选“生成图片保存”，直接把所选对话保存成图片来分享，就不再受链接长度限制。

#### 2.3 显示与公式

**公式显示不正常？** 公式渲染用的是网站自带的本地字体文件，正常情况下断网也能显示。如果确实显示成 `$…$` 原文，先刷新页面；仍然不行的话，检查网站目录里的 `vendor/katex/` 是否完整（本地打开或自己部署时容易漏传这个文件夹）。

**下划线怎么看着是断开的？** 已经处理过：下划线粗细统一为 1px，并且关掉了浏览器在 g / y / p 这类字母处“跳过一段”的默认行为，中英文混排也是连成一条线。

#### 2.4 笔记与编辑

**笔记图片太多会怎样？** 图片和笔记会占用浏览器存储空间。如果存储空间不足，保存可能失败，页面会明确提示。建议导出备份后清理不必要的大图；插入时也可以先用“确认压缩”把图片压小。

**编辑后能恢复原始内容吗？** 编辑只保存在本地。取消编辑可以恢复当前编辑前的内容。如果已经保存，需要手动改回，或清除该模块数据后重新打开。

**在粗体后面接着写，怎么取消粗体？** 点工具栏上的“🧹 清除格式”：选了字就去掉选中部分的样式；只是光标停着，就关掉“接下来打字会带上的样式”，后面打的字即恢复正常。直接再点一次对应的 **B** / *I* / <u>U</u> 也可以取消。

## 九、技术说明与总结

### 1. 技术构成

本知识库是纯静态网页，主要技术包括 HTML / CSS / JavaScript、浏览器 localStorage 本地存储、语音合成 API、文件读取 API、Canvas 图片压缩、Markdown 渲染、LaTeX 公式渲染（本地 KaTeX）和流式 AI 接口调用。数据不会自动上传到云端。AI 对话会发送到所配置的 API 服务商，请自行注意 API Key 和隐私安全。

### 2. shared 目录

九个页面共用的部分放在 `shared/` 目录：确认弹窗（`confirm.js`）、存储安全（`storage-guard.js`）、板块串连导航（`section-nav.js`）、筛选记忆（`filter-memory.js`）、文本转义（`escape.js`）、富文本笔记（`rich-note.js`）。改一处，九个页面同时生效。

### 3. 总结

本知识库适合经济学考研的长期复习和冲刺阶段使用。核心用法可以概括为：用八大模块系统学习，用顶栏序号在模块之间直接切换，用卡片展开答案、收藏、笔记、编辑，用筛选和搜索定位内容，用随机抽查检验记忆，用自测模式检查掌握程度，用 AI 助手答疑，用“我的卡片”沉淀自己的东西，用学习进度记录计划，用朗读功能辅助复习，用数据同步定期备份。建议把“收藏 + 笔记 + 随机抽查 + 自测 + 真题模拟 + 导出备份”作为固定学习闭环，坚持使用，效果最好。
