## 一、说明

本文件用于记录每个 part 需要编辑的错漏之处，例如部分代码被吞导致内容缺失或未加载、对照纸质书发现的识别错误和漏内容、勘误文档处的编辑。看到一个记一个，没看到不用管，不需要为此修改网页，直接在编辑处改着用。现在的网站只能算 demo，不用追求完美。这样也方便在不小心破坏格式或清除数据时，记录哪里更改过，后续补回。

## 二、版本与存储策略

目前 pure 网页为简单版本，不再持续更新，本地保存其原始代码。

full 网页的更新代码直接在 GitHub 编辑页完成，本地保存为第二个版本；1 个主页、8 个网页及 js 文件都未更新。等后续修复到一定阶段、不再更改后，再在本地保存文件。

### 26/09/15

（39）自测模式下，答案没遮住时 AI 能读到，遮住时读不到；AI 会锁定当前正在看的那张卡片。

（40）修掉了手机端「点一下按钮样式粘住、必须点旁边才恢复」的问题：把没有做设备判断的 `:hover` 规则收进 `@media (hover: hover) and (pointer: fine)`，并给触摸端补上 `:active` 按下反馈（按下轻微缩小或变色，松手立刻复原）。搜索框的绿色光圈是 `:focus`，表示光标在这里可以打字，保留不动。

（41）收藏、笔记、编辑、插图、保存、清空这几个按钮的事件处理器接回正确位置，八个子页一致；清空弹窗只在点「🗑️ 清空」时出现。

（42）小于号和转义：数据统一存裸字符 `<` `>`，显示时的转义只由 `shared/escape.js` 负责。连带修掉三个问题——编辑时「< 后面跟英文字母」被浏览器当成 HTML 标签、把后面的内容整段吞掉；页面上字面显示 `&lt;`；以及搜索「<」搜不全。

（43）关于「**」：只有「计算要点」页的 `**` 是真正的加粗标记，其余页面里的 `**` 全是数学记号（`w**`、`X**`），原样显示是对的，不要推广加粗渲染，否则会把 `w*` 和 `w**` 中间的正文误吞掉。

（44）筛选下拉框改成从数据自动生成，以后加章节 / 加专题只要改数据，不用再手改 HTML 里的选项列表。没在显示名里列到的值会按原值出现在最前面，不会再被漏掉。

（45）配置里的 API Key 输入框改成普通文本框 + CSS 圆点遮罩（看起来还是像密码框），浏览器不再当它是登录凭据、不再弹「保存密码」。

（46）结构上的四处整理：搜索框加防抖（打字过程中不重画，停下来才画一次）；卡片上的按钮改成事件委托，只绑一次，不再每次重画都重新绑；确认弹窗抽成 `shared/confirm.js`；「存储安全」（图片压缩 + 笔记自动保存 + 离开提醒）抽成 `shared/storage-guard.js`。

（47）KaTeX 公式库改成本地 `vendor/katex/`，不再走 CDN（国内 CDN 慢或被拦时公式会退化成 `$…$` 原文），万一 `vendor/` 没传上去会自动兜底回 CDN；取消编辑的提示图标换成 🔙。

（48）PWA：九个页面补齐图标与 `manifest.webmanifest` 声明，手机上可装到主屏当应用用（需要 HTTPS + 用网址打开）。图标定为浅紫底五瓣花，方角满幅、四角不留白；应用名和页面标题保持「南开经济学 · 知识库」不变；主题色南开紫 `#6A2C91`（手机浏览器顶栏会同步变紫）。换图标时残留在页面顶部的一行代码尾巴已清除。

### 26/09/17

（53）筛选下拉框动效调整：点击时重新显示绿色光圈动效（与此前风格一致），选中下拉列表里的某一项后光圈自动消失；搜索框光圈照旧保留。

（54）分享链接变短：分享内容改用紧凑格式 + UTF-16 打包 + base64url 编码，同样内容的链接长度大约缩短三分之一以上，转发时更不容易被截断；旧版链接仍然可以打开。

（55）修复「有笔记的卡片点📝仍会跳进编辑」的间歇问题：原因是个别编辑器进入过编辑态后状态没复原，下次点📝时自动聚焦又把光标带了进去（编辑过一次才出现、刷新后消失，就是这个缘故）。现在点📝只打开查看、不再自动聚焦；保存笔记或点出编辑框都会回到查看态。

（56）分享升级：分享栏按钮由「生成链接」改为「生成分享」，点击后可二选一——「生成链接」（原来的复制分享链接）或「生成图片保存」（把勾选的几条对话渲染成一张图片，先预览、可保存到相册或下载；内容多、链接太长时用图片分享更合适）。图片在本地生成，不经过任何服务器。

（57）分享图片预览：点「保存图片」后，保存成功（或浏览器中已开始下载）时预览面板自动关闭，不用再手动点「关闭」；保存失败时仍保留预览，方便重试或长按图片另存。「保存图片」按钮去掉图标，更简洁；分享图片顶部不再显示「选自××知识库」和时间信息，卡片高度随之变矮，顶部绿色调浅；图片底部署名去掉知识库名称（保留「由 AI 答疑助手生成 · 仅供学习交流」）。

（58）勾选分享的稳定性：修复偶发的「勾选后点生成分享却提示无可分享内容」——原因是对话刷新重画时，勾选的高亮和选择框被清掉了。现在重画会原样保留勾选状态；处于勾选模式时再点「分享」也不再无反应，而是自动补齐选择框与选择条计数，避免状态错位。
