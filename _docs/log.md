## 一、说明

本文件用于记录每个 part 需要编辑的错漏之处，例如部分代码被吞导致内容缺失或未加载、对照纸质书发现的识别错误和漏内容、勘误文档处的编辑。看到一个记一个，没看到不用管，不需要为此修改网页，直接在编辑处改着用。现在的网站只能算 demo，不用追求完美。这样也方便在不小心破坏格式或清除数据时，记录哪里更改过，后续补回。

## 二、版本与存储策略

目前 pure 网页为简单版本，不再持续更新，本地保存其原始代码。

full 网页的更新代码直接在 GitHub 编辑页完成，本地保存为第二个版本；1 个主页、8 个网页及 js 文件都未更新。等后续修复到一定阶段、不再更改后，再在本地保存文件。

> ！GitHub 那个文件夹下载下来的目录配置，本地也能用！如果需要对外分享就可以按文件分享而不是给网站，防止泄露了。

## 五、后续可新增的功能

### 26/09/22

（1）同步升级：用服务器保存数据（现在是各端浏览器各自存储）。

（2）账号权限：增加登录机制或单独密码权限，一人一用，防止成果被剽窃或引来版权纠纷。

（3）图片笔记：极易把浏览器存储撑爆、导出 json 也冗长，日后让图片笔记在备份时可以单独勾选。

（4）AI 复制：回复最好支持只复制选中片段（目前可先存成卡片，再在卡片段落里复制，更精准但麻烦）。

（5）AI 分享图：顶部略空，可在下方自动生成一排知识点标签小字，一看就知道对话在讲哪部分。

（6）AI 思考显示：AI 若在思考目前看不见输出，可考虑加思考显示用于测试（也可能嫌烦，不一定加）。

（7）deepseek-chat 疑点：官方说 7 月 24 日已停用，实际仍可用且明显比 flash 快（v4-pro 则慢得出奇）；若后续真失效，需改代码在请求体里加思考速度设置，才能关掉 flash 的思考模式。

（8）AI 回复速度：目前有限制但体感刚好——一问马上跳大段答案反而不好；暂停只是视觉暂停、后台仍在耗 tokens，用于提问后自己来了思路、不想被输出干扰的场景。

（9）语音朗读（首页）：学习进度区朗读可加“循环播放”和“定时关闭”两个按钮，设计参考同步球。

（10）语音朗读（子页）：可加朗读 / 点读模式——每张卡可选择朗读，展开答案与不展开答案读法不同，筛选功能对朗读生效，可暂停和单卡 / 列表 / 循环 / 随机播放；自测模式要不要配朗读（方便听不熟的卡）待定。

（11）公式与语音：答案区现有公式格式不要变动——这种形式语音能识别朗读，换成 LaTeX 就读不出了；以后或可探索公式自动转自然语言朗读（可能需要 AI 中转，太费 tokens 就不用）。

（12）紫色主题：可另出一版紫色主色调项目——主页、子页、AI 页都紫，收藏色调改粉色（星星或可换成粉色爱心），使用说明卡仍蓝色，自测模式绿黄红不变，更有私人风格、也更贴 NKU 校徽；需测试紫色是否影响阅读，榴莲日记里紫色主题观感不错，但粉紫容易看腻（相关 demo 配色已存一版）。

（13）配色体系：可参考榴莲日记的思路——定一个主色号，配套色用低饱和的同系色，再配相应的反色做收藏色（绿配蓝、紫配粉）。

（14）计算要点校对：识别出不少学校名称错误——现阶段手机电脑各以一个网页为基准，出错处直接在题目上编辑，之后导出数据即可看出改过哪些卡。

（15）7 子页编辑区：题目、答案编辑区不支持富文本，若改坏了可从本地路径打开网页，把里面的初始内容粘贴回来。

（16）我的卡片：或可按标签搜索并弹窗预览原库对应卡片（相当于预览窗口，不是真跳回库界面）；和自测、朗读模式怎么安排还要看，比较难设计。

（17）复试库：可以往里新增复试内容——但必须先修完其他问题再加，底层逻辑相通，不然一次要改的页面更多。

（18）子页互跳：可考虑子页之间内联互跳，不必先回主页再跳（建议新标签页打开而不是直接跳转）。

（19）自娱自乐：做产品设计图和推广图。
